This repo is the frontend codebase for [spellbound](https://github.com/spellboundreads/), a responsive, modern web application for discovering, reviewing, and tracking books. Built with **Next.js**, **React**, **TailwindCSS**, and **shadcn**.

---

## ⚙️ Local Development Setup
1. Clone the repository
```bash
git clone https://github.com/spellboundreads/frontend
cd frontend
```

2. Install dependencies and start the development server
```bash
npm install
npm run dev
```
